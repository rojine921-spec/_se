# 智帳 Smart Expense｜AI 智慧記帳與消費分析

## 習題 3：專案價值

**問題**：學生或一般使用者常不清楚錢花在哪裡，手動分類與彙整又很花時間。

**使用價值**：使用者可記錄每日支出，系統依消費描述自動建議分類，使用圖表查看各類支出、每日消費趨勢，並在預算接近或超出時提醒。適合學生、租屋族、個人記帳。

**商業價值（構想，尚未實際收費或驗證）**：可開發成免費基本記帳與付費進階報表的訂閱服務，也能替社團或小型店家客製化簡易收支統計系統。正式商用前需加入會員管理、備份、資料保護及更多測試。

## 功能
1. 新增、刪除支出紀錄
2. 根據文字自動推薦分類（可人工修改）
3. 依月份統計支出總額、分類分布與每日趨勢
4. 設定每月預算；80% 與超額提醒
5. 產生資料驅動的消費分析建議
6. CSV 匯出當月支出
7. SQLite 儲存（資料保留在本機）

## 執行方法
需要 Python 3.9 以上，**無須 pip 安裝任何套件**。

在 VS Code 開啟此資料夾，於終端機輸入：

```bash
python app.py
```

瀏覽器開啟 `http://localhost:8000`。結束程式可按 Ctrl+C。

Windows 若 `python` 指令無法使用，可試 `py app.py`。

## 測試

```bash
python -m unittest test_app.py -v
```

## 技術架構
- 前端：HTML / CSS / JavaScript，Fetch API
- 後端：Python `http.server`，JSON API
- 資料庫：SQLite (`expenses.db` 執行時自動產生)
- 智慧分類：**關鍵字規則**（可解釋、免付費、可離線）；不是訓練模型或外部生成式 AI API，請勿在報告宣稱已串接 ChatGPT API。
- 圖表：HTML/CSS 原生長條圖

## 展示步驟
1. 新增「午餐便當」120 元 → 分類建議「餐飲」
2. 新增「捷運」30 元 → 分類建議「交通」
3. 設定當月預算 140 元 → 系統提醒已超出預算
4. 查看分類圖表、每日趨勢及消費明細
5. 匯出 CSV 驗證資料

## API
- `GET /api/summary?month=YYYY-MM`
- `POST /api/predict`：`{"note":"捷運"}`
- `POST /api/expense`：`{"date":"2026-10-27","amount":120,"note":"午餐","category":"餐飲"}`
- `POST /api/budget`：`{"month":"2026-10","amount":10000}`
- `POST /api/delete`：`{"id":1}`
- `GET /api/export?month=YYYY-MM`

## 注意
此專案為課程示範版，不設帳號密碼，僅綁定本機 `127.0.0.1`，請不要直接部署成公開金融服務。請勿輸入銀行密碼、帳戶資訊等敏感資料。刪除 `expenses.db` 會清空資料，建議先匯出 CSV。
